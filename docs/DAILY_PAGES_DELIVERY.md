# 日常计算与 Pages 发布

网页新建私有工作空间使用 `.github/workflows/daily.yml` 调用中央同名工作流，固定完整引擎提交 SHA。

一个 job 恢复最新缓存、同步 Zotero、更新画像和索引、计算推荐、完成 AI 处理、生成 RSS 和阅读页。
只缓存数据库与当前计算/兴趣模型、当前画像和可复用的 AI/元数据缓存，不缓存历次运行报告或旧模型代次。
新缓存保存成功后清理同一命名空间的旧缓存；缓存缺失、文库不匹配或 SQLite 不可读时重建。

最终只有 feed.xml、feed.xsl 和 index.html 上传为短期公开页面包。
网页后端用此工作仓库独立的发布 token 鉴权，将页面包的临时下载地址交给公开结果仓库。
结果仓库使用 GitHub Actions 部署自身 Pages；只有初始化时提交接收工作流，日常不创建页面提交或回执提交。
跨仓库发布依赖网页后端和有效的 GitHub 授权；发布失败时保留已有页面。

状态缓存包含 Zotero 文库和兴趣信息，工作仓库保持私有。没有旧的 SQLite 检查点、内部结果或诊断附件上传，也没有状态分支写入。
内部 machine result 和诊断文件仍可在 job 内供 AI 使用，运行结束后丢弃。

本流程只用于新版网页创建的工作空间，旧工作流不自动迁移。
